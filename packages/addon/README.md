# @figma-token-sync/addon

Storybook addon for Figma token synchronization.

## Status

This package is planned for **Tier 2+** implementation.

## Planned Features

- Visual token browser in Storybook
- Live preview of token changes
- Integration with Storybook's theming system
- Token documentation generation

## Development Timeline

1. **Tier 1 (Current)**: CLI foundation
2. **Tier 2**: Storybook addon with basic token display
3. **Tier 3**: Advanced addon features and integrations
